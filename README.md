# Travel-Diary

Steps needed to start the project-
-> npm install (To add all the dependencies required for the project)
To run frontend -> cd into frontend-> then cd into travel-app->npm run dev
To run Backend -> cd into backend->npm start

About the project-

Travel-Diary is a digital platform where users can login and add their travel experiences and then they can search/manage their travel experiences accordingly.
The project follows MERN stack where the frontend is built using React and Tailwind CSS.
The backend is written in Node.js and data is stored in MongoDB.
The REST APIs are written with the help of Express.js which has a good compatibility with Node.js
