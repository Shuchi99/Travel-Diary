# Travel-Diary

Steps needed to start the project-<br>
-> npm install (To add all the dependencies required for the project)<br>
To run frontend -> cd into frontend-> then cd into travel-app->npm run dev<br>
To run Backend -> cd into backend->npm start<br>

About the project-

Travel-Diary is a digital platform where users can login and add their travel experiences and then they can search/manage their travel experiences accordingly.<br>
The project follows MERN stack where the frontend is built using React and Tailwind CSS.<br>
The backend is written in Node.js and data is stored in MongoDB.<br>
The REST APIs are written with the help of Express.js which has a good compatibility with Node.js<br>
